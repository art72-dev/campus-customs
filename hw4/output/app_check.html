Bugs found by this testing, and fixed

The first test run's screenshots exposed three problems. All were fixed, and every screenshot above is from the final run after the fixes.

FoundCauseFix
Yale Dad Crewneck photo had black patches between the sleeves and the body and a speckled dark outlineThe background cleanup only whitened black connected to the photo's edge; gaps enclosed by an arm were missedThe photo cleanup (now tools.prepare_product_photos()) also whitens large, flat, pure-black enclosed areas (average brightness ≤ 5 of 255). Dark navy fabric shadows (average 11–15) are left alone, and black crest prints are kept. Re-scanned all 102 photos.
Fixed photos could still show the old versionThe photo URL's version number came from the folder's timestamp, which doesn't change when files are overwrittenThe version now comes from the newest photo file, so browsers fetch the fresh photos
After a category question, the page heading still said "All the merch"Chat "browse" results didn't pass Audrey's title to the pageThe page now shows "Chat search · picked by Audrey" with the title and keywords. Manual filters get a matching heading (e.g. "Navy Hoodies"), and the chat title is dropped if the shopper changes the filters themselves.

How this was tested (and how to re-run it)

  1. Start the backend from backend/: uvicorn main:app --reload --port 8000
  2. Start the website from frontend/: npm run dev
  3. Run the check from frontend/: npm run app-check

The script (frontend/scripts/app_check.cjs) opens headless Google Chrome, clicks and types exactly as a shopper would, waits for Audrey's reply, saves the screenshots to output/app_check_images/, and records everything that appeared on screen (replies, cards, counts, URLs, card heights, photo corner colors) in output/app_check_images/results.json. Numbers were then checked with the SQL shown under each check.
